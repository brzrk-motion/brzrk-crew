# brzrk-crew MVP UX brief

Build a focused chat workspace rather than five disconnected chat tabs.

## Layout
- Left rail: brand, new conversation, conversation history.
- Center: message timeline and composer.
- Right rail: crew and active delegation status; collapses on tablet/mobile.
- Mobile: one-column timeline with drawers for history and crew.

## Core states
Empty, ready, sending, manager thinking, delegating, specialist working, streaming, completed, failed, cancelled, reconnecting.

Every status uses text plus icon/motion; never color alone. Preserve partial output on failure. Provide stop/retry controls. Use semantic landmarks, keyboard navigation, visible focus, labels for icon buttons, polite announcements for new responses, and reduced-motion support.

## Delegation group
Show the manager’s assignment, specialist name/role, task, status, elapsed time, returned result, handoff context, and final manager synthesis. The user must always know which agent produced which response.

## Visual direction
Deep ink/navy, fog/light surfaces, one primary accent, restrained specialist accents, thin dividers, modest radii, compact spacing, and strong typography. Nautical flavor should be abstract and functional, not skeuomorphic.
