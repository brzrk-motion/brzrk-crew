# brzrk-crew MVP workflow brief

## Status contract
`assigned` → `active` → `blocked` or `handoff` → `verification` → `PR opened` → `CI result` → `complete`

Every event includes owner, objective, artifact/link, evidence/status, next action, and approval requirement.

## Initial workflows
- Coding: Breakwater owns the branch; Wake independently reviews; PR/CI states are recorded; James approves merge.
- Research: Reef records source URLs, dates, confidence, ranking rationale, and falsifiers.
- Studio outreach: Tide drafts from verifiable public evidence; James approves recipient, wording, channel, and timing before sending.
- Documentation: Swell receives implementation context, updates the smallest accurate surface, and links source PRs.
- Review: Wake checks acceptance criteria, correctness, security, regressions, and missing tests without silently rewriting the implementation.

## Approval boundary
Research, drafts, local edits, tests, branches, and PR preparation may be automated within scope. External outreach, publishing, spending, deletion, production changes, and merging require explicit James approval.

## Acceptance test
James can issue one outcome-oriented request, observe assignment-to-completion, inspect handoffs and evidence, approve a consequential step, and recover the exact artifact without manually coordinating every specialist.
